# Islamic AI Agent 🕌

An intelligent Islamic AI agent built with React that provides Islamic knowledge, Quran verses, Hadith references, and spiritual guidance.

## Features

- 🤖 **AI-Powered Responses**: Intelligent responses to Islamic queries
- 📖 **Quran Integration**: Access to Quranic verses and interpretations
- 📚 **Hadith Database**: Authentic Hadith references and explanations
- 🕌 **Islamic Guidance**: Spiritual and practical Islamic advice
- 🌙 **Beautiful UI**: Modern, responsive design with Islamic aesthetics
- 💬 **Real-time Chat**: Interactive chat interface
- 📱 **Mobile Friendly**: Responsive design for all devices
- Interactive Islamic Q&A
- Prayer time guidance
- Quranic verses with translations
- Authentic Hadith collection
- Islamic calendar integration
- Duas and Dhikr
- Fiqh rulings and guidance
## Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd islamic-ai-agent
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
